HumanPen

HumanPen is a document-level AI polish tool: import a Turnitin or iThenticate AI detection report (or pick paragraphs yourself), rewrite only the flagged sections, and keep layout, citations, formulas, numbers, and meaning as intact as possible. You are billed for words actually rewritten—not for the whole draft. Signup includes 100 free credits that never expire, and the same balance works across the web tools and the API. Start at https://humanpen.net.

What HumanPen supports (verified on the product site, 7 Nov 2026)

  • Report-driven rewrites — import a Turnitin or iThenticate report and rewrite only the flagged passages; you are billed only for the words actually rewritten.
  • 35 languages in the rewrite engine (translation covers 12 languages; citation format correction is language-agnostic).
  • Native PPTX — each slide's text is rewritten in place; the editable PPTX comes back with layout, charts, masters and speaker notes intact.
  • No word limit, formatting intact — DOCX, PPTX and TXT, with original styling untouched however long the document; editable files in, editable files out.
  • 100 free credits on signup; credits never expire and the same balance works across the web tools and the API.
  • Hard content stays frozen — numbers, units, formulas, citations, terminology and claim strength are kept exactly as they were, with no deliberate typos to fool detectors.

Authorship is not the same as an AI score. No tool can prove you are the original author, but you can build an evidence chain. We do not promise a passing score or "undetectable" text.
